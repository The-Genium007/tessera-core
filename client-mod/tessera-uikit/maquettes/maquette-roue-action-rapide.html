Roue d'action rapide [G]

Bouge la souris dans l'écran : l'angle + la distance depuis le centre visent une tuile (cran + pulsation). Clic : une catégorie s'ouvre ; un élément se VALIDE (la roue se ferme, reset racine, l'action part). Échap : retour. G : rouvrir. Émotes = 14 éléments sur DEUX cercles.
