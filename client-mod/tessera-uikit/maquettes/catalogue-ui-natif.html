Tessera · Catalogue UI natif

Ce que le moteur (ink) accepte

Le vocabulaire d'interface natif du jeu — widgets, contrôleurs, et la charte graphique existante qu'on réutilise (styles, atlas, police, couleurs). Chaque élément est une approximation CSS annotée avec sa classe de widget réelle (dump RTTI) et sa ressource native (depot path à référencer en ink). But : reprendre les codes graphiques du jeu, pas inventer.
