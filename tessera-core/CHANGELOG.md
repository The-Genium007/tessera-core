# Changelog

Toutes les modifications notables de ce projet sont documentées ici.

Le format suit [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/), et ce projet
adhère au [Semantic Versioning](https://semver.org/lang/fr/) une fois la version 1.0.0
publiée. Avant 1.0.0, l'API et le protocole peuvent changer sans préavis entre versions
mineures.

Chaque entrée est dérivée des commits [Conventional Commits](https://www.conventionalcommits.org/)
(`feat:`, `fix:`, `docs:`, etc. — voir [CONTRIBUTING.md](CONTRIBUTING.md)) fusionnés sur
la branche `main`.
